# 📊 Bank Loan Analytics Dashboard (Excel)

## 📌 Project Overview
This project analyzes bank loan data using Microsoft Excel to understand loan trends, payment behavior, and customer risk profiles. The project focuses on transforming raw data into meaningful business insights through analysis and visualization.

## 📂 Dataset
- Finance_1: Loan and customer information  
- Finance_2: Payment and revolving balance details  

## 🔧 Tools Used
- Microsoft Excel  
- Power Query  
- Pivot Tables  
- Charts & Slicers  

## 📈 Business Problems Solved
1. Year-wise loan amount statistics  
2. Grade & sub-grade wise revolving balance  
3. Total payment comparison for verified vs non-verified customers  
4. State-wise and month-wise loan status analysis  
5. Home ownership vs last payment date analysis  

## 🧠 Key Learnings
- Data cleaning and preparation  
- Merging datasets using Power Query  
- Analytical thinking with pivot tables  
- Building interactive dashboards in Excel
